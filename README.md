# LEOPARD

LEOPARD — програма керування комп’ютерним клубом, побудована на C#, .NET 10, Avalonia UI та MVVM.

**Основна технічна документація:** [повна документація LEOPARD](docs/LEOPARD-DOCUMENTATION.md).

**Робота команди:** задачі ведуться в [GitHub Issues](https://github.com/stanislavslobodyan/leopard-club-management/issues). Правила процесу описані в [командному таск-менеджменті](docs/TEAM-WORKFLOW.md), а структура вимог для нових задач — у [шаблоні технічного завдання](docs/TECHNICAL-TASK-TEMPLATE.md).

У документації LEOPARD є команди запуску в CMD і розгортання на другому ПК, посібник адміністратора, формула нарахування вартості, вимоги, MVC/MVVM, діаграма класів, дизайн, PC Agent і відомі обмеження.
