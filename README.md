# LEOPARD — система керування комп’ютерним клубом

LEOPARD — настільна програма для адміністратора клубу на C#, .NET 10, Avalonia UI та MVVM. Вона веде локальний облік робочих місць, клієнтів, тарифів, активних сеансів, бронювань, історії та нарахованої за тарифами суми.

## Можливості

- Облік ПК із процесором, відеокартою, RAM, монітором і накопичувачем.
- Додавання клієнтів і тарифів.
- Старт, подовження та завершення сеансу; живий таймер, пошук і фільтри.
- Бронювання з перевіркою конфліктів часу.
- Історія завершених сеансів, денний підсумок нарахувань і бонусні бали.
- Внутрішні сповіщення про завершення часу.
- Опційна перевірка online/offline через окремий PC Agent.
- Компактний layout для вузького вікна.

Сума сеансу розраховується за фактичним часом і тарифом та зберігається при завершенні. Це нарахування для внутрішнього обліку, не запис фактичного платежу. LEOPARD наразі не підключена до каси чи платіжного сервісу й не веде грошовий гаманець клієнта.

## Запуск у Windows CMD

Потрібні Windows 10/11 і .NET 10 SDK. Для завантаження приватного репозиторію також потрібен Git та доступ до GitHub-акаунта, якому надали доступ.

```cmd
git clone https://github.com/stanislavslobodyan/leopard-club-management.git
cd /d leopard-club-management
dotnet restore LEOPARD.slnx
dotnet run --project src\LEOPARD\LEOPARD.csproj
```

Якщо проєкт уже завантажений, відкрий CMD у його кореневій папці та виконай `dotnet run --project src\LEOPARD\LEOPARD.csproj`.

Збірка:

```cmd
dotnet build LEOPARD.slnx -c Release
```

## Запуск на другому ПК без .NET

На ПК розробки створи автономний Windows x64 output:

```cmd
dotnet publish src\LEOPARD\LEOPARD.csproj -c Release -r win-x64 --self-contained true -o publish\LEOPARD
```

Скопіюй **усю** папку `publish\LEOPARD` на другий ПК та запусти `LEOPARD.exe`. Встановлювати Avalonia або .NET на другому ПК не потрібно. Дивись [інструкцію зі встановлення](docs/INSTALLATION.md).

Для вузлів клубу, де потрібна лише перевірка зв’язку, публікуй і копіюй `publish\PC-Agent` окремо:

```cmd
dotnet publish src\LEOPARD.PcAgent\LEOPARD.PcAgent.csproj -c Release -r win-x64 --self-contained true -o publish\PC-Agent
```

## Перше налаштування клубу

Нова база порожня. Додай власні комп’ютери, тарифи й клієнтів у відповідних розділах. Потім натисни **Почати сеанс** і вибери ПК, клієнта, гру, тариф і тривалість.

LEOPARD зберігає дані в `%LOCALAPPDATA%\LEOPARD\club.sqlite3`. База належить поточному Windows-профілю й автоматично не синхронізується з іншими ПК. Перед копіюванням файлу бази закрий програму.

## Технології та архітектура

| Розділ | Технології |
|---|---|
| BackEnd | C#, .NET 10, SQLite, Microsoft.Data.Sqlite |
| FrontEnd | Avalonia UI, AXAML, CommunityToolkit.Mvvm |
| Testing | `dotnet build` та ручний сценарій у посібнику; окремого автоматизованого test project поки немає |
| Design | Темна адмінпанель LEOPARD, адаптивні картки, специфікація у `docs/DESIGN-SPEC.md`; Figma-файл не створювався |

MVVM відокремлює XAML-подання від стану й команд ViewModel та предметного доступу до даних. Пояснення MVC/MVVM та порівняння Avalonia, WPF, WinUI 3 і .NET MAUI є у [вимогах та технологіях](docs/REQUIREMENTS.md).

## Межі поточної версії

- Дані локальні: серверної синхронізації й кількох адміністративних робочих місць немає.
- Нарахована сума не підтверджує оплату; немає каси, еквайрингу, фіскальних чеків чи грошового балансу клієнта.
- PC Agent перевіряє тільки доступність HTTP endpoint-а. Він не блокує ПК, не запускає ігри й не читає апаратні характеристики.
- Android target не налаштований; компактний вигляд — це адаптація desktop-вікна.
